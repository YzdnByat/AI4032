# AI4032_MP1 - Titanic Survival Prediction & Linear Regression

This mini-project focuses on data analysis and regression modeling using the 

Titanic Dataset. The primary goal is to predict passenger survival using various features and to practice key data science techniques.

# Core Concepts

- Exploratory Data Analysis (EDA): A comprehensive analysis of the dataset's structure, correlations, and distributions.


- Data Preprocessing: Handling missing values, converting numerical and categorical features, and applying normalization or standardization.


- Feature Selection: Implementing methods like Lasso Regression and Recursive Feature Elimination to select the most impactful features for the model.


- Model Training & Evaluation: Training binary and multinomial logistic regression models and evaluating their performance using metrics such as confusion matrices, ROC curves, and AUC.
