# AI4032_MP2 - Neural Networks & Collaborative Machine Learning
This mini-project explores the fundamentals of neural networks and the concept of collaborative machine learning.

# Core Concepts

- Perceptron Implementation: Designing a simple perceptron (McCulloch-Pitts neuron) to classify a specific triangular region in a 2D space.


- Neural Network Design: Implementing a simple neural network from scratch for a regression problem, using an SGD optimizer and MSE cost function. The hidden layer uses a  ReLU activation function, and the output layer uses a Linear function.


- Robustness Analysis: Implementing a Hamming or Hopfield network to handle noisy data and missing points.


- Collaborative Learning: A simulation of a collaborative machine learning system for weather forecasting.
