# AI4032_MP3 - Fuzzy Systems & Mobile Robotics Control

This mini-project focuses on the design and implementation of fuzzy systems for function approximation and mobile robot control.


# Core Concepts

- Fuzzy System Design: Designing a fuzzy Mamdani system using gradient descent for function approximation. The project also involves designing fuzzy systems with mean and maximum defuzzifiers.


- Function Approximation: Approximating unknown functions using fuzzy systems, including a time-series prediction problem (Mackey-Glass series) using a lookup table.
- 

- Fuzzy Control: Designing a fuzzy controller to guide a 2D mobile robot to a target position. The controller uses distance and angle differences as inputs to generate appropriate linear and angular velocities.
