# AI4032 - Artificial-Intelligence Projects

This repository contains a collection of mini-projects and assignments from the AI4032 - Artificial-Intelligence course at K. N. Toosi University of Technology, taught by Dr. Mahdi Aliyari-Shoorehdeli. These projects cover a range of practical and theoretical concepts in artificial intelligence and machine learning.

The repository is organized into separate directories, with each mini-project having its own dedicated folder containing code notebooks and a detailed report.

 # Key Features
- Fundamental Concepts: Practical implementation of core machine learning and deep learning algorithms.

- Diverse Applications: Projects address problems in data analysis, pattern recognition, and robotic control.

- Structured Code: All code is well-organized in Google Colab notebooks with clear sections and visible outputs.

- Comprehensive Analysis: Each project includes a detailed analysis and report of the results.

 # Project Structure
- AI4032_MP1: Titanic Survival Prediction & Linear Regression

- AI4032_MP2: Neural Networks & Collaborative Machine Learning

- AI4032_MP3: Fuzzy Systems & Mobile Robotics Control
